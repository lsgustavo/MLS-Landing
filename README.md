# MLS Landing — Maria Luiza Salles

Landing page estática de Estruturação Contratual.

## Desenvolvimento

Abra `index.html` com Live Server (raiz do projeto).

## Deploy — GitHub Pages

1. Faça push deste repositório para o GitHub
2. Em **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` (ou `master`)
   - Folder: **/ (root)**
3. Aguarde 1–2 minutos e acesse:
   `https://lsgustavo.github.io/MLS-Landing/`

O arquivo `.nojekyll` garante que o GitHub Pages sirva os arquivos estáticos sem processar com Jekyll.

## Outros hostings

- **Netlify / Vercel:** publique a raiz do repositório
- Domínio próprio: atualize as URLs em `index.html`, `robots.txt` e `sitemap.xml`
